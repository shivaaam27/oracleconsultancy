Everyday how-tos

To…Do this
Create a taskPress + on Home/Tasks → title, company, priority, assignees.
Add a person/people → add; an onboarding + compliance checklist is created automatically.
Upload a document/documents → "Add several" for bulk; it auto-links to the compliance checklist.
Capture a meeting/meeting → dictate/notes → Generate minutes → Extract action items → bulk-create tasks.
Approve leave/hrms/leave (admin) or portal home (managers).
Mark attendance/hrms/leave → Attendance → brush the grid, or "mark all Present today".
Issue a letter/letters → pick template → edit → Draft → Issue (freezes letterhead + ref).
Send the brief/brief → WhatsApp / Email / Copy, or print to PDF.
Chase a compliance gapNeeds-attention row → "Chase" → drafts a reminder in the Outbox.
Archive someonePerson drawer → archive; offboarding checklist + asset auto-return run.
