No dark fills

No black header band and no black button. The white page, a light grey canvas and one blue button — so a mail app that forces its own dark mode has nothing heavy to flip.

Follows the device

Apple Mail, iPhone and Outlook for Mac read the email's own dark set. Gmail and Outlook on the web darken it themselves — a light design with no dark blocks survives that cleanly.

Worst first

Overdue rows lead each company, then soonest due. The pink pill says how late; amber means due within three days; everything else shows its priority quietly.

NewEvery row is a door

Each task shows its code and opens that task in the portal. Today the rows are plain text and only the button at the bottom goes anywhere.

NewA “due this week” count

Beside open and overdue. One task reads “Your task” with its title in the subject line (already fixed).

One layout for every email

Masthead, title, figures, grouped rows, one button, sign-off. The renewals, overdue and event emails take the same shell next — built once in the shared email layout.
