Staff · the plan

Staff on the new screens

The same Studio as the owner and directors — Home, Tasks, a task page, Calendar, People — showing only their own work. Nothing a member of staff can do today is lost; nothing they cannot do is added.

What they can do (as the code allows today)

  • See and open the tasks they are on or raised — nobody else's.
  • Post an update, attach a file, @mention, message a teammate.
  • Move a task to In Progress, Under Review (“send for review”) or Blocked — never Completed or Closed.
  • Complete a task only if they raised it, with a note (and a file where proof is required).
  • Tick, add and rename subtasks on their tasks.
  • Check in each day (Present · Remote · Half-day · Sick) and see their week.
  • Their own to-do list, with a reminder time.
  • Profile: edit their contact details, send a document, passkeys, password, alerts, install the app.
  • Read and acknowledge announcements; chat.

What they cannot

  • Create tasks for others, bulk-edit, repeat rules, copy across companies.
  • See other people's tasks, the Outbox, Insights or the Report.
  • Edit a task's fields (deadline, priority, people) — they ask whoever runs it.
  • Pin or take down anyone's update but their own.

Where the old portal pages go

  • Home → Home (their greeting card, check-in, diary, late work, to-dos).
  • My tasks (on Home) → Tasks, its own page, like everyone else.
  • Briefings → meetings in Calendar; announcements as a banner on Home + the Announcements page (until it is rebuilt, the current one).
  • Directory → People, view-only: their colleagues, call / WhatsApp / email.
  • Activity → the Updates card on Tasks.
  • Profile → Profile, rebuilt in the same look.
  • Chat → stays the current Chat until it is rebuilt.
